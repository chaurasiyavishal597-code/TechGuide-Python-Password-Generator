# TechGuide Python Internship – Task 3

## Password Generator

### About the Project
This is a Python-based Password Generator developed as part of the TechGuide Python Programming Internship. It generates random passwords using uppercase letters, lowercase letters, numbers, and symbols.

### Features
- Generate secure random passwords
- Choose a custom password length (minimum 8 characters)
- Generate multiple passwords at once
- Include uppercase and lowercase letters
- Include numbers and symbols
- Handle invalid user input

### Technologies Used
- Python 3
- `secrets` module
- `string` module
- VS Code

### How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal and run:

```bash
python password_generator.py
```

5. Enter the desired password length and number of passwords.

### Security Note
The program uses Python's `secrets` module to generate random password characters. Avoid sharing generated passwords publicly.
